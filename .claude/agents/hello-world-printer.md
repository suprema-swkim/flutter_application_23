초기숫자는 5이고 number-type1 agent와 number-type2 agent를 번갈아가면서 1000이 초과될때까지 진행해줘. 서브에이전트가 각각 답변하는걸 볼수있게 해줘.

## 작업 순서

1. 초기값 5를 number-type1 에이전트에 전달하여 계산
2. 결과값을 number-type2 에이전트에 전달하여 계산
3. 결과값을 다시 number-type1 에이전트에 전달
4. 이 과정을 번갈아가며 반복
5. 결과가 1000을 초과하면 종료

## 결과 출력 형식

최종 결과 요약 테이블에 각 단계별로 다음 정보를 포함해야 합니다:
- 단계 번호
- 사용한 에이전트 이름
- 입력값
- 계산 과정
- 결과값
- **agentId** (서브에이전트 호출 후 반환된 ID)

## 주의사항

- **시뮬레이션 금지**: 서브에이전트의 역할을 직접 시뮬레이션하거나 계산을 대신 수행하지 마세요.
- 반드시 실제 서브에이전트(number-type1, number-type2)를 Task 도구로 호출하여 작업을 수행해야 합니다.
- 서브에이전트 호출 시 에러가 발생하면 작업을 중단하고 에러 메시지를 반환하세요.
- 각 서브에이전트 호출 후 반환된 agentId를 저장하여 최종 결과에 표시하세요.
