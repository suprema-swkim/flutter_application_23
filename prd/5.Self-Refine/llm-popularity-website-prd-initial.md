# LLM 인기도 웹사이트 PRD (초안)

## 1. 프로젝트 개요

### 1.1 목적
AI 분야에서 사용되는 다양한 LLM(Large Language Model)의 종류와 인기도를 시각적으로 보여주는 웹사이트를 개발한다.

### 1.2 배경
최근 AI 기술이 급속히 발전하면서 다양한 LLM이 출시되고 있다. 개발자와 연구자들이 어떤 LLM이 인기 있는지, 어떤 특징을 가지고 있는지 쉽게 파악할 수 있는 플랫폼이 필요하다.

## 2. 핵심 기능

### 2.1 LLM 목록 및 정보 표시
- 주요 LLM들의 목록을 카드 형태로 표시
- 각 LLM의 기본 정보 (제작사, 출시일, 파라미터 수, 라이선스 등)
- LLM별 특징 및 용도 설명

### 2.2 인기도 지표 시각화
- GitHub Stars 수
- 다운로드/사용 통계
- 논문 인용 수
- 커뮤니티 활동도
- 트렌드 그래프 (시간에 따른 인기도 변화)

### 2.3 비교 기능
- 여러 LLM을 선택하여 비교
- 비교 항목: 성능, 비용, 속도, 지원 언어 등

### 2.4 검색 및 필터링
- LLM 이름으로 검색
- 제작사, 라이선스, 용도별 필터링
- 정렬 기능 (인기도순, 출시일순, 파라미터순 등)

## 3. 기술 스택

### 3.1 프론트엔드
- Flutter Web (현재 프로젝트 기반)
- 차트 라이브러리 (인기도 시각화)

### 3.2 데이터 소스
- GitHub API (Stars, Forks 등)
- Hugging Face API (다운로드 통계)
- Google Scholar / Semantic Scholar API (논문 인용)
- 커뮤니티 포럼 데이터 (Reddit, Discord 등)

### 3.3 데이터 저장
- 로컬 캐싱 (성능 최적화)
- 주기적인 데이터 업데이트

## 4. 사용자 경험

### 4.1 메인 페이지
- 인기 LLM Top 10 카드 뷰
- 실시간 트렌드 차트
- 빠른 검색 바

### 4.2 상세 페이지
- LLM별 상세 정보
- 인기도 그래프
- 관련 링크 및 리소스

### 4.3 비교 페이지
- 선택한 LLM들의 나란한 비교 테이블
- 시각적 비교 차트

## 5. 성공 지표

- 일일 방문자 수
- 평균 세션 시간
- 검색 및 비교 기능 사용률
- 사용자 피드백 점수

## 6. 개발 일정

### Phase 1 (2주)
- 기본 UI/UX 구현
- 정적 데이터로 LLM 목록 표시

### Phase 2 (2주)
- API 연동 및 데이터 수집
- 인기도 지표 계산 로직 구현

### Phase 3 (1주)
- 비교 기능 구현
- 검색 및 필터링 기능

### Phase 4 (1주)
- 최적화 및 버그 수정
- 배포

## 7. 제약사항

- 외부 API 사용량 제한
- 데이터 업데이트 주기 (일일/주간)
- 무료 API 사용 범위 내에서 운영
