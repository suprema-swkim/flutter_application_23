# LLM 인기도 웹사이트 PRD (Product Requirements Document)

## 1. 프로젝트 개요

### 1.1 프로젝트명
**LLM Popularity Tracker** (LLM 인기도 추적기)

### 1.2 프로젝트 목적
AI 분야에서 사용되는 다양한 Large Language Model (LLM)의 종류와 인기도를 시각적으로 보여주는 웹사이트를 개발합니다. 사용자들이 현재 시장에서 활발히 사용되는 LLM들을 한눈에 파악하고, 각 모델의 인기도 지표를 비교할 수 있도록 합니다.

### 1.3 플랫폼
- **주요 플랫폼**: Flutter Web
- **타겟 브라우저**: Chrome, Firefox, Safari, Edge (최신 2개 버전)
- **반응형 지원**: 데스크톱, 태블릿, 모바일

### 1.4 프로젝트 범위
- LLM 목록 조회 및 검색
- 인기도 지표 시각화
- LLM 상세 정보 제공
- 실시간 또는 주기적 데이터 업데이트

---

## 2. 목표 및 목적

### 2.1 주요 목표
1. **정보 제공**: 다양한 LLM 모델에 대한 종합적인 정보 제공
2. **시각화**: 인기도 지표를 직관적인 차트와 그래프로 표현
3. **비교 분석**: 여러 LLM을 쉽게 비교할 수 있는 인터페이스 제공
4. **접근성**: 누구나 쉽게 접근하고 이해할 수 있는 사용자 경험

### 2.2 타겟 사용자
- **주요 타겟**: AI 개발자, 연구자, 기술 의사결정자
- **보조 타겟**: AI에 관심이 있는 일반 사용자, 학생
- **사용자 특성**: 
  - LLM 기술에 대한 기본적인 이해가 있는 사용자
  - 최신 AI 트렌드를 파악하고자 하는 사용자

### 2.3 비즈니스 가치
- AI 커뮤니티에 유용한 정보 제공
- LLM 시장 동향 파악 지원
- 오픈소스 프로젝트 또는 교육 목적으로 활용 가능

## 3. 기능 요구사항

### 3.1 핵심 기능

#### 3.1.1 LLM 목록 표시
- **기능 설명**: 등록된 모든 LLM 모델을 카드 형태 또는 리스트 형태로 표시
- **표시 정보**:
  - 모델 이름
  - 개발사/기관
  - 출시일
  - 현재 인기도 점수
  - 모델 타입 (예: GPT, BERT, LLaMA 등)
  - 주요 특징 태그
- **우선순위**: 높음

#### 3.1.2 인기도 지표 시각화
- **기능 설명**: 다양한 차트와 그래프를 통해 인기도를 시각적으로 표현
- **차트 유형**:
  - 막대 그래프: LLM별 인기도 비교
  - 라인 차트: 시간에 따른 인기도 변화 추이
  - 파이 차트: 모델 타입별 분포
  - 히트맵: 기간별 인기도 변화
- **인기도 지표**:
  - GitHub Stars
  - 다운로드 수
  - 논문 인용 수
  - 커뮤니티 활동도
  - 종합 인기도 점수
- **우선순위**: 높음

#### 3.1.3 필터링 및 검색 기능
- **검색 기능**:
  - 모델 이름으로 검색
  - 개발사/기관으로 검색
  - 태그/키워드 검색
- **필터링 옵션**:
  - 모델 타입별 필터
  - 출시 연도별 필터
  - 인기도 범위 필터
  - 오픈소스/상용 모델 필터
- **우선순위**: 중간

#### 3.1.4 정렬 기능
- **정렬 옵션**:
  - 인기도 점수 (높은 순/낮은 순)
  - 모델 이름 (가나다순/알파벳순)
  - 출시일 (최신순/오래된 순)
  - GitHub Stars 수
- **우선순위**: 중간

#### 3.1.5 상세 정보 페이지
- **기능 설명**: 각 LLM에 대한 상세 정보를 제공하는 전용 페이지
- **표시 정보**:
  - 모델 개요 및 설명
  - 기술 사양 (파라미터 수, 컨텍스트 길이 등)
  - 성능 벤치마크 결과
  - 인기도 추이 그래프
  - 관련 링크 (논문, GitHub, 공식 사이트)
  - 사용 사례 및 예시
- **우선순위**: 높음

#### 3.1.6 반응형 디자인
- **기능 설명**: 다양한 화면 크기에 최적화된 레이아웃
- **화면 크기별 대응**:
  - 데스크톱 (1920px 이상): 전체 기능 표시, 다중 컬럼 레이아웃
  - 태블릿 (768px ~ 1919px): 적응형 레이아웃, 터치 최적화
  - 모바일 (767px 이하): 단일 컬럼, 간소화된 UI
- **우선순위**: 높음

### 3.2 부가 기능

#### 3.2.1 즐겨찾기 기능
- 사용자가 관심 있는 LLM을 즐겨찾기로 저장
- 로컬 스토리지 활용
- 우선순위: 낮음

#### 3.2.2 비교 기능

- 비교 테이블 형태로 표시
- 우선순위: 낮음

#### 3.2.3 다크 모드
- 라이트/다크 테마 전환
- 사용자 설정 저장
- 우선순위: 낮음

## 7. 데이터 모델

### 7.1 LLM 정보 구조

```dart
class LLMModel {
  final String id;                    // 고유 식별자
  final String name;                  // 모델 이름
  final String developer;             // 개발사/기관
  final DateTime releaseDate;         // 출시일
  final String modelType;             // 모델 타입 (GPT, BERT, LLaMA 등)
  final String description;           // 모델 설명
  final int parameterCount;           // 파라미터 수
  final int contextLength;            // 컨텍스트 길이
  final bool isOpenSource;            // 오픈소스 여부
  final List<String> tags;             // 태그 목록
  final PopularityMetrics popularity; // 인기도 지표
  final List<String> links;           // 관련 링크
  final Map<String, dynamic> specs;   // 추가 기술 사양
}

class PopularityMetrics {
  final int githubStars;              // GitHub Stars 수
  final int downloadCount;             // 다운로드 수
  final int citationCount;             // 논문 인용 수
  final double communityActivity;      // 커뮤니티 활동도 (0-1)
  final double overallScore;          // 종합 인기도 점수 (0-100)
  final List<PopularityDataPoint> history; // 시간별 인기도 추이
}

class PopularityDataPoint {
  final DateTime date;                // 날짜
  final double score;                 // 해당 날짜의 점수
}
```

### 7.2 API 응답 형식

#### 7.2.1 LLM 목록 조회
```
GET /api/llms?page=1&limit=20&filter=...&sort=...

Response:
{
  "success": true,
  "data": {
    "llms": [
      {
        "id": "gpt-4",
        "name": "GPT-4",
        "developer": "OpenAI",
        ...
      }
    ],
    "total": 50,
    "page": 1,
    "limit": 20
  }
}
```

#### 7.2.2 LLM 상세 정보
```
GET /api/llms/{id}

Response:
{
  "success": true,
  "data": {
    "id": "gpt-4",
    "name": "GPT-4",
    ...
    "popularity": {
      "githubStars": 0,
      "downloadCount": 1000000,
      ...
      "history": [
        {"date": "2024-01-01", "score": 85.5},
        ...
      ]
    }
  }
}
```

### 7.3 인기도 지표 정의
- **GitHub Stars**: GitHub 저장소의 Star 수 (오픈소스 모델)
- **다운로드 수**: 모델 다운로드 통계 (Hugging Face, 공식 사이트 등)
- **논문 인용 수**: 관련 논문의 인용 횟수
- **커뮤니티 활동도**: 포럼, Reddit, Twitter 등에서의 언급 빈도
- **종합 점수**: 위 지표들을 가중 평균하여 계산한 종합 인기도 점수
